# 🏡 Darhub – Real Estate Marketplace Web Application

**Darhub** is a full-stack real estate platform where users can **buy**, **sell**, and **manage** properties online. Designed with a modern tech stack and scalable architecture, Darhub features role-based access, property management, real-time chat, interactive maps, and admin moderation tools.

🚀 **Live Demo:** [https://darhub.vercel.app](https://darhub.vercel.app)

## 🧰 Tech Stack

**Frontend:**

- React.js
- Zustand (state management)
- Material UI (MUI)
- Sass, AOS, Swiper, Quill Editor
- Leaflet (map integration)

**Backend:**

- Node.js
- Express.js
- MongoDB (via Prisma ORM)
- JWT Authentication
- Socket.IO (for chat)
- Dotenv, CORS, Bcrypt, Cookie-parser

## ✅ Features

### 👥 User Roles & Authentication

- Role-based registration: **Admin**, **Developer**, and **Normal** users
- Secure login and signup with JWT-based authentication
- Protected routes and dashboard access based on role

### 🧑‍💼 Admin Dashboard

- Manage users (view, remove)
- Manage property listings: **approve**, **reject**, or **delete**
- View all activities across the platform

### 🏠 Property Management

- Users can **list** properties for sale with detailed descriptions, pricing, and images
- Buyers can **browse**, **filter**, and **search** properties
- Admin approval is required before listings appear publicly

### 📍 Location Mapping

- Integrated with **Leaflet** for map-based location visualization
- Users can view the exact property location on the map

### 🔍 Property Filtering

- Filter properties by:
  - Price
  - Location
  - Type (apartment, house, etc.)

### 🗨️ Real-Time Chat

- Built with **Socket.IO**
- Users can chat directly with property owners
- Chat history maintained during sessions

### 👤 User Dashboard

- View own listings
- Update profile information
- Delete listings or edit existing ones
- View public profiles of property owners

### 🎨 Frontend Experience

- Clean, modern UI with **Material UI**
- Smooth animations with **AOS**
- Responsive design across mobile, tablet, and desktop
